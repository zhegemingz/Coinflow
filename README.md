# Coinflow 智能记账系统

这是一个基于Python和PyQt5开发的桌面记账应用程序，旨在帮助用户管理个人和家庭财务。

## 功能概述

当前版本实现了基础的开始界面，包含三个主要功能按钮：

1. **添加账目** - 用于记录收入和支出
2. **查看统计图表** - 展示财务数据分析和可视化
3. **进入家庭界面** - 家庭协作功能入口

## 技术栈

- Python 3.x
- PyQt5 - 用于GUI开发

## 安装指南

1. 确保安装了Python 3.x

2. 安装所需依赖：

```bash
pip install PyQt5
```

## 运行程序

在项目目录下执行以下命令：

```bash
python main.py
```
